    校园互助服务平台 


一、项目启动步骤


1. 安装依赖
   pip install Django Pillow

2. 数据库迁移
   python manage.py makemigrations accounts demands locations notifications
   python manage.py migrate

3. 初始化数据（生成管理员、学生账号、校园位置、欢迎公告）
   python manage.py init_data

4. 启动服务
   python manage.py runserver 8000

5. 浏览器访问
   http://127.0.0.1:8000/

测试账号：
   管理员：admin / admin123
   学生1：student1 / 123456
   学生2：student2 / 123456
   学生3：student3 / 123456

二、普通学生操作流程

注册和登录
操作路径：
  首页 → 点击右上角「注册」→ 填写用户名/昵称/学号/密码
  → 注册成功 → 跳转登录页 → 输入用户名和密码 → 登录成功 → 回到首页

说明：
  登录后导航栏会显示：用户昵称、信誉积分（★ 100分）、未读消息数
  未登录用户无法发布需求和响应需求，会自动跳转到登录页


发布需求（核心流程）
操作路径：
  导航栏点击「发布需求」→ 填写表单 → 点击「发布需求」→ 跳转到需求详情页

表单内容：
  标题：例如 "借一把雨伞"
  需求类型：物品租借 / 学习互助 / 事务求助 / 兼职对接 / 失物招领
  详细描述：写清楚具体的需求内容
  位置：从下拉框选择校园位置（16个预设位置，如第一食堂、中心图书馆等）
  截止时间：可选填
  是否紧急：可勾选，标记后在列表中会显示红色"紧急"标签

注意：
  信誉积分低于60分的用户将被限制发布需求


浏览和搜索需求
操作路径：
  导航栏点击「需求大厅」→ 查看所有已发布的需求

筛选功能：
  按类型筛选：物品租借 / 学习互助 / 事务求助 / 兼职对接 / 失物招领
  按区域筛选：宿舍区 / 教学楼 / 食堂 / 图书馆 / 体育馆 / 超市等
  按具体位置筛选：如 "第一食堂"、"中心图书馆"
  按关键词搜索：搜索标题和内容
  排序方式：最新发布 / 紧急优先 / 信誉最高

每条需求卡片显示：
  需求类型标签（彩色）
  标题和内容摘要
  发布者昵称和信誉分
  位置标签（蓝色，如 📍 第一食堂）
  发布时间、浏览次数、响应数

响应他人的需求
操作路径：
  需求大厅 → 点击某条需求进入详情页
  → 页面底部填写响应内容 → 点击「提交响应」

说明：
  不能响应自己发布的需求
  每人对同一需求只能响应一次
  提交响应后，需求发布者会收到消息通知


处理响应（需求发布者操作）
操作路径：
  收到响应通知 → 点击进入需求详情页 → 查看所有响应列表

可执行操作：
  点击「接受」：接受该响应，其他所有响应自动变为"已拒绝"
  点击「拒绝」：拒绝该响应

说明：
  响应者会收到接受/拒绝的消息通知
  接受响应后，需求状态变为「已响应」


确认完成
操作路径：
  互助完成后 → 需求发布者进入需求详情页 → 点击「确认完成」

积分变动：
  需求发布者：+5 信誉分
  响应者：+5 信誉分
  双方都会收到消息通知


双方互评
操作路径：
  需求完成后 → 进入需求详情页 → 底部出现评价表单
  → 选择评分（1-5分）→ 填写评价内容 → 点击「提交评价」

评分对信誉积分的影响：
  评 4-5 分（好评）→ 被评价者 +3 分
  评 3 分（中评）  → 不变
  评 1-2 分（差评）→ 被评价者 -5 分

说明：
  需求发布者评价响应者，响应者评价发布者
  每人只能评价一次
  评价后信誉变动会记录在信誉积分中心


个人中心
操作路径：
  点击导航栏用户名 →「个人中心」

页面内容：
  左侧：头像、昵称、角色、信誉积分、平均评分、个人信息
  右侧：发布需求数、响应数、评价数统计
  快捷入口：我的需求、我的响应、发布需求、我的消息
  信誉变动记录表（时间、变动值、原因）

可执行操作：
  编辑资料：修改昵称、学号、手机、简介、上传头像
  修改密码：输入旧密码和新密码


信誉积分中心
操作路径：
  导航栏点击「 xx分」 或 下拉菜单点击「信誉积分」

页面内容：
  当前信誉积分（大字显示）
  信誉等级：优秀（>=80分）/ 一般（60-79分）/ 过低（<60分）
  累计加分和累计扣分统计
  积分规则说明表
  完整的积分变动记录（时间、变动值、原因、相关需求链接）

积分规则：
  注册账号：初始 100 分
  完成互助需求（发布者）：+5 分
  完成互助需求（响应者）：+5 分
  收到好评（4-5分）：+3 分
  收到中评（3分）：不变
  收到差评（1-2分）：-5 分
  管理员手动调整：视情况而定
  信誉分低于60分将被限制发布需求


位置功能项目特色

a) 校园地图
   操作路径：导航栏点击「校园地图」
   页面左侧：Leaflet地图，标注16个校园位置
   每个位置显示名称和活跃需求数量
   点击地图标注弹窗，查看位置详情，可跳转该位置所有需求
   页面右侧：位置列表，点击可定位到地图对应位置

b) 按位置筛选需求
   操作路径：需求大厅 → 选择区域或具体位置 → 点击筛选
   可按区域筛选（如只看宿舍区的需求）
   可按具体位置筛选（如只看第一食堂的需求）

c) 附近需求推荐
   操作路径：需求详情页 → 右侧栏「附近需求」
   自动显示同一位置的其他活跃需求

d) 位置标签展示
   每条需求卡片和详情页都显示蓝色位置标签

预设校园位置（16个）：
   宿舍区：1号宿舍楼、2号宿舍楼、3号宿舍楼、4号宿舍楼
   教学楼：第一教学楼、第二教学楼、实验楼
   食  堂：第一食堂、第二食堂
   图书馆：中心图书馆
   体育馆：体育馆、田径场
   超  市：校内超市
   校  门：学校正门、学校北门
   办公区：行政楼


消息通知
操作路径：
  导航栏点击「消息」→ 查看所有通知

消息类型：
  响应通知：有人响应了你的需求
  状态通知：你的响应被接受/拒绝
  信誉通知：积分发生变动
  系统消息：管理员操作通知

操作：
  单条标记已读
  全部标记已读
  点击「查看」跳转到相关需求


系统公告
操作路径：
  导航栏点击「公告」→ 查看所有系统公告 → 点击可查看详情


三、管理员操作流程

登录方式：
  使用 admin / admin123 登录
  → 导航栏用户下拉菜单出现「管理后台」入口（蓝色高亮）

数据概览仪表盘
操作路径：管理后台首页
页面内容：
  统计卡片：注册用户数、总需求数、待审核数、已完成数、响应数、评价数
  需求类型分布（各类型数量统计）
  位置需求热度 TOP10（哪些位置需求最多）
  最近发布的需求列表


用户管理
操作路径：管理后台 → 左侧菜单「用户管理」
功能：
  查看所有用户列表（ID、用户名、昵称、学号、角色、信誉分、状态、注册时间）
  搜索用户（按用户名/昵称/学号）
  启用/禁用用户（禁用后用户无法登录）
  设置角色（普通学生 ↔ 管理员）
  手动调整信誉积分（输入分值和原因，用户会收到通知）


需求管理

操作路径：管理后台 → 左侧菜单「需求管理」

功能：
  查看所有需求（按状态和类型筛选）
  审核通过：待审核的需求 → 点击「通过」→ 变为已发布
  驳回需求：点击「驳回」→ 需求被取消
  删除需求：直接删除
  用户会收到审核结果的消息通知

【4】位置管理
操作路径：管理后台 → 左侧菜单「位置管理」

功能：
  查看所有校园位置及关联需求数量
  添加新位置：填写名称、所属区域、经纬度、描述
  编辑已有位置信息
  删除位置


公告管理
操作路径：管理后台 → 左侧菜单「公告管理」

功能：
  查看所有公告列表
  发布新公告：填写标题和内容
  显示/隐藏公告（隐藏后前台不展示）
  删除公告

五、项目技术

1. 校园位置定位系统
   16个预设校园位置，支持经纬度
   Leaflet.js 地图可视化标注
   按区域/位置筛选需求
   附近需求智能推荐

2. 信誉积分体系
   初始100分，根据行为动态变化
   完成互助+5分，好评+3分，差评-5分
   低于60分限制发布，形成约束机制
   完整的积分变动记录和规则说明

3. 完整业务闭环
   发布 → 响应 → 接受 → 完成 → 评价
   每个环节都有消息通知
   状态流转清晰可控

4. 双角色权限分离
   普通学生：发布需求、响应需求、评价
   管理员：用户管理、需求审核、位置管理、公告管理
   装饰器控制权限，未授权自动拦截

5. 纯Django全栈架构
   Django MTV 模式，模板引擎渲染
   不依赖 Vue/React 等前端框架
   不使用前后端分离，一个项目直接运行
   支持 SQLite（开发）和 MySQL（生产）

6. 数据库设计
   8张核心表：用户、需求、位置、响应、评价、信誉记录、公告、消息
   外键关联，数据完整性保证
